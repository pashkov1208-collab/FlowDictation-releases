# FlowDictation

Диктовка в любом приложении: зажмите сочетание клавиш, говорите, отпустите — текст появится
там, где стоит курсор. Распознавание идёт локально (whisper.cpp), без интернета.

Здесь лежат только готовые сборки. Установленное приложение само проверяет этот репозиторий
и обновляется в фоне.

## Скачать

Откройте [последний релиз](../../releases/latest):

- **macOS** (Apple Silicon, macOS 14+): `FlowDictation-<версия>.dmg` — перетащите в «Программы».
  При первом запуске: Системные настройки → Конфиденциальность и безопасность →
  «Всё равно открыть».
- **Windows** 10/11 x64: `FlowDictation-<версия>-windows.zip` — распакуйте папку
  `FlowDictation` в `%LOCALAPPDATA%\Programs\` и запустите `FlowDictation.exe`
  (SmartScreen: «Подробнее» → «Выполнить в любом случае»).

Остальные файлы релиза (`appcast.xml`, `windows.json`, `*-mac.zip`) — для автообновления.
Обновления подписаны: приложение не установит файл, подпись которого не совпала.
